## logging


Уровни важности (Log Levels)
Это константы, определяющие, насколько критично сообщение (по возрастанию):


**logging.DEBUG** (10) — Детальная информация для поиска ошибок и отладки.

**logging.INFO** (20) — Подтверждение того, что всё работает как ожидается (штатные события).

**logging.WARNING** (30) — Предупреждение (например, "мало места на диске"), но программа продолжает работу. (Уровень по умолчанию).

**logging.ERROR** (40) — Ошибка, из-за которой программа не смогла выполнить какую-то функцию.

**logging.CRITICAL** (50) — Серьезный сбой, программа может упасть.



Базовая настройка
**logging.basicConfig(kwargs)** — Быстрая настройка корневого (root) логгера. Задает уровень отсечения, формат сообщений и файл для записи. Работает только при первом вызове (последующие вызовы игнорируются).


Функции для отправки сообщений
**logging.debug(msg) / logging.info(msg) / logging.warning(msg) / logging.error(msg) / logging.critical(msg)** — Отправка лога соответствующего уровня.

**logging.exception(msg)** — Отправляет лог уровня ERROR и автоматически прикрепляет traceback (стек вызовов ошибки). Используется только внутри блока except.


Продвинутые компоненты (ООП-подход)
**Loggers (Логгеры): logging.getLogger(name)** — Создает или возвращает именованный объект логгера (чтобы разделять логи разных модулей).

*Handlers* (Обработчики): Определяют, куда пойдет лог.

**logging.StreamHandler()** — Вывод в консоль (sys.stderr или sys.stdout).

**logging.FileHandler(filename)** — Запись в файл.



(Из модуля logging.handlers): RotatingFileHandler (ротация по размеру файла), TimedRotatingFileHandler (ротация по времени).

Formatters (Форматировщики): logging.Formatter(fmt) — Задает шаблон (внешний вид) сообщения (время, уровень, имя файла, сам текст).

Filters (Фильтры): logging.Filter(name) — Позволяет настроить сложную логику, какие логи пропускать, а какие — нет.

# PathLib

В pathlib главный класс — это Path. Почти вся работа строится вокруг него.

Создание и навигация
**Path("папка/файл.txt")** — Создает объект пути.

**Path.cwd()** — Возвращает текущую рабочую директорию (Current Working Directory).

**Path.home()** — Возвращает домашнюю директорию пользователя.

path1 / "subfolder" / "file.txt" — Магия pathlib: использование оператора деления / для элегантного склеивания путей.

Чтение свойств пути (без обращения к диску)
path.name — Имя файла с расширением (например, script.py).

*path.stem* — Имя файла без расширения (script).

*path.suffix* — Расширение файла (.py).

*path.parent* — Родительская папка.

*path.parts* — Кортеж из всех компонентов пути (например, ('C:', 'Users', 'Admin')).

Проверки (обращение к диску)
**path.exists()** — Существует ли такой файл или папка?

**path.is_file() / path.is_dir()** — Это файл? Это папка?

Действия с файловой системой
path.mkdir(parents=True, exist_ok=True) — Создать папку. parents=True создает все промежуточные папки, exist_ok=True не выдает ошибку, если папка уже есть.

**path.touch()** — Создать пустой файл (как в Linux).

**path.unlink()** — Удалить файл.

**path.rmdir()** — Удалить папку (она должна быть пустой).

**path.rename(new_path)** — Переименовать/переместить.



Чтение и запись (Быстрый I/O)
**path.read_text(encoding="utf-8")** — Читает весь файл как строку (не нужно писать with open(...)).

**path.write_text("текст")** — Записывает строку в файл, перезаписывая его.

Поиск и обход
**path.iterdir()** — Возвращает генератор с содержимым папки (файлы и подпапки).

**path.glob("*.txt")** — Поиск файлов по маске в текущей папке.

**path.rglob("*.py")** — Рекурсивный поиск (поиск во всех вложенных папках).

# Enum

Перечисление (Enum) — это набор символических имен, привязанных к уникальным, неизменным значениям. Они нужны для описания конечных состояний системы: дни недели, статусы заказов, цвета светофора, состояния узлов в графе (Не посещен, В процессе, Посещен).


Базовые классы
**Enum** — Стандартный базовый класс для создания перечислений.

IntEnum — Наследник от int и Enum. Его элементы можно сравнивать с обычными числами (например, Status.NEW == 1 вернет True).

StrEnum (Python 3.11+) — Наследник от str и Enum. Полезно, когда API требует строковых статусов, но внутри кода хочется строгости.

Flag / IntFlag — Перечисления, поддерживающие побитовые операции (|, &, ~). Идеально для комбинирования прав доступа (например, READ | WRITE).

Создание и контроль значений
**auto()** — Функция-помощник. Автоматически назначает значения элементам (обычно это 1, 2, 3...), чтобы тебе не приходилось писать их руками.

*@unique* — Декоратор (из модуля enum). Выкинет ошибку ValueError при запуске кода, если ты случайно задал двум разным именам одинаковые значения.

Доступ и свойства элементов (Members)
*Member.name* — Возвращает имя элемента в виде строки (например, "RED").

**Member.value** — Возвращает значение элемента (например, 1 или "red_color").

**MyEnum(value)** — Доступ по значению (выдаст элемент MyEnum.RED, если передать 1).

**MyEnum['NAME']** — Доступ по имени (выдаст элемент MyEnum.RED, если передать строку "RED").

**list(MyEnum)** — Превращает перечисление в список всех его элементов.

# Регулярные выражения **RE**


Основные функции модуля re:

**re.search(pattern, string)** — ищет первое совпадение.

**re.fullmatch(pattern, string)** — проверяет, соответствует ли вся строка шаблону.

**re.findall(pattern, string)** — возвращает список всех непересекающихся совпадений.

**re.finditer(pattern, string)** — возвращает итератор match-объектов.

**re.split(pattern, string)** — разбивает строку по шаблону.

**re.sub(pattern, repl, string)** — заменяет совпадения на строку или результат функции.
