# LIBRARY HELP



## logging


Уровни важности (Log Levels)
Это константы, определяющие, насколько критично сообщение (по возрастанию):


**logging.DEBUG** (10) — Детальная информация для поиска ошибок и отладки.

**logging.INFO** (20) — Подтверждение того, что всё работает как ожидается (штатные события).

**logging.WARNING** (30) — Предупреждение (например, "мало места на диске"), но программа продолжает работу. (Уровень по умолчанию).

**logging.ERROR** (40) — Ошибка, из-за которой программа не смогла выполнить какую-то функцию.

**logging.CRITICAL** (50) — Серьезный сбой, программа может упасть.



Базовая настройка
**logging.basicConfig(kwargs)** — Быстрая настройка корневого (root) логгера. Задает уровень отсечения, формат сообщений и файл для записи. Работает только при первом вызове (последующие вызовы игнорируются).


Функции для отправки сообщений
**logging.debug(msg) / logging.info(msg) / logging.warning(msg) / logging.error(msg) / logging.critical(msg)** — Отправка лога соответствующего уровня.

**logging.exception(msg)** — Отправляет лог уровня ERROR и автоматически прикрепляет traceback (стек вызовов ошибки). Используется только внутри блока except.


Продвинутые компоненты (ООП-подход)
**Loggers (Логгеры): logging.getLogger(name)** — Создает или возвращает именованный объект логгера (чтобы разделять логи разных модулей).

*Handlers* (Обработчики): Определяют, куда пойдет лог.

**logging.StreamHandler()** — Вывод в консоль (sys.stderr или sys.stdout).

**logging.FileHandler(filename)** — Запись в файл.



(Из модуля logging.handlers): RotatingFileHandler (ротация по размеру файла), TimedRotatingFileHandler (ротация по времени).

Formatters (Форматировщики): logging.Formatter(fmt) — Задает шаблон (внешний вид) сообщения (время, уровень, имя файла, сам текст).

Filters (Фильтры): logging.Filter(name) — Позволяет настроить сложную логику, какие логи пропускать, а какие — нет.
